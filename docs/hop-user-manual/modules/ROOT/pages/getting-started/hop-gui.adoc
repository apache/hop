= Hop Gui overview

Hop Gui is where you build, run, preview and debug workflows and pipelines.

Before we start building, here's a short tour so you know what you're looking at.

== Start Hop Gui

[tabs]
====
Windows::
+
--
[source,shell]
----
hop-gui.bat
----
--

Linux, macOS::
+
--
[source,shell]
----
./hop-gui.sh
----
--
====

== The main window

image:getting-started/gs-hop-gui-overview-1.png[The Hop Gui window]

{nbsp} +

The window has five parts.

image:getting-started/gs-hop-gui-overview-2.png[The parts of the Hop Gui window]

. The **main toolbar**, along the top, opens the Hop menu, creates new files (pipelines, workflows, metadata), opens and saves them, and opens the Marketplace.
. The **perspectives toolbar**, down the left-hand side, switches between the different things you can do in Hop Gui.
The two buttons at the bottom of it show or hide the execution results and the bottom panel.
. The **active perspective**, here File Explorer, with its own toolbar.
In File Explorer, the toolbar acts on the files and folders of your project, including git operations.
. The **open file**, with a tab for each pipeline or workflow you have open and the toolbar of its editor: run, stop, check, undo and redo, and zoom.
. The **status bar**, along the bottom, shows the active project and environment and, when the project is in a git repository, the current branch.
You'll use the project and environment in xref:getting-started/hop-projects.adoc[Projects and environments].

== Perspectives

A perspective is a mode of the whole window.
You'll spend nearly all of your time in the first one, File Explorer, which is where you browse your project and edit pipelines and workflows.

include::../snippets/hop-gui/perspectives-list.adoc[]

Switch perspective by clicking its icon, or cycle through them with `CTRL-SHIFT-arrow-up` and `CTRL-SHIFT-arrow-down`.

== Worth knowing early

Click anywhere::
Most of Hop Gui is driven by clicking on empty canvas or on an item, which opens a context dialog with everything you can do from there.
You'll use it constantly in the next chapter.

`CTRL-F` searches everything::
Not just the open file: it searches metadata, pipelines and workflows across the project.
See xref:hop-gui/perspective-search.adoc[Search].

There are shortcuts for most things::
See xref:hop-gui/shortcuts.adoc[Keyboard Shortcuts].

TIP: the xref:hop-gui/index.adoc[Hop Gui] section of this manual has the detailed tour, including how to xref:hop-gui/disable-ui-elements.adoc[hide parts of the UI] for new users.
