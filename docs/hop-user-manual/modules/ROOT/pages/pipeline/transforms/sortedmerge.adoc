== Description

The Sorted Merge transform merges rows coming from multiple input transforms providing these rows are sorted themselves on the given key fields.

Every input must be sorted on the key fields in the direction set for each field in the Fields table. The transform merges in that direction, even when a transform before it sorted the rows the other way. When a row of an input sorts before the previous row of the same input, the transform stops with an error naming the input and the two rows, rather than merging the rows in the wrong place. Verify pipeline warns when a previous transform, such as Sort rows, sorts a key field descending while the merge sorts it ascending. Get fields sets Ascending to N for a field the previous transform says it sorted descending, as Sort rows does, and to Y for the other fields.

== Options

[options="header"]
|===
|Option|Description
|Transform name|Name of the transform this name has to be unique in a single pipeline.
|Fields table|Specify the field name and sort direction (ascending/descending); click Get Fields to retrieve a list of fields from the input stream(s).
|===

== Samples

The samples project has `transforms/sorted-merge.hpl`, which merges two Data grids sorted on `value`, 10, 20, 50, 80 and 30, 40, 60, 90, into one stream of 8 rows that is still sorted on `value`.
