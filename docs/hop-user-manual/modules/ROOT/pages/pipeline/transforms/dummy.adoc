== Description

The Dummy transform passes data without making any modifications.

It functions as a placeholder for testing purposes or a way to combine multiple streams with the same field layout.

== Options

[options="header"]
|===
|Option|Description
|Transform name|Name of the transform.
|===

== Samples

The samples project has:

* `pipelines/read-transactions.hpl`, where the Dummy transforms `Headers` and `Data` receive the header row and the data rows of the Excel files.
* `loops/pipeline-executor.hpl` and `loops/workflow-executor.hpl`, which end each output stream of the executor in a Dummy transform.
