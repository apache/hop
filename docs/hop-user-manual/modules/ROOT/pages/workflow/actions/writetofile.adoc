= Write to File

== Description

The `Write to file` action writes the text you enter in the action to a file. Variables in the text are resolved.

== Options

[options="header", width="90%", cols="1,3"]
|===
|Option|Description
2+|File
|Action name|The name of the workflow action.
|File name|The file directory and name.
|Browse...|Browse the filesystem for a file location.
|Create parent folder|Whether to create the parent folder.
|Append file|Will overwrite the previous file if unchecked, if checked it will append new text to the previous file.
2+|Content
|Encoding|The encoding to use while writing the file.
|Text|The text to write to the file.
|===

== Result

What this action passes on to the next action. See xref:workflow/action-results.adoc[Action results] for how results travel through a workflow.

[options="header", width="90%", cols="1,3"]
|===
|Result|Value
|True|The text was written to the file.
|False|No file name is set, the parent folder does not exist and *Create parent folder* is not selected, the file cannot be written (for example in a read-only folder), or the encoding is not known. The number of errors is 1.
|Result files|Passed on unchanged. The written file is not added.
|Result rows|Passed on unchanged.
|===
