= Check if a folder is empty

== Description

The `Check if a folder is empty` action verifies that a folder holds no files. Subfolders do not count, only the files in them with *Include subfolders*.

== Options

[options="header", width="90%", cols="1,3"]
|===
|Option|Description
|Action name|The name of the workflow action.
|Folder name|The name of the folder to verify for emptiness.
|Include subfolders|Also look for files in the subfolders of the folder.
|Limit search to (RegExp)|Only count the files whose name matches *Wildcard (RegExp)*.
|Wildcard (RegExp)|The regular expression for the file names, for example `+.*\.txt+`. Only used with *Limit search to (RegExp)*.
|===


== Result

What this action passes on to the next action. See xref:workflow/action-results.adoc[Action results] for how results travel through a workflow.

[options="header", width="90%", cols="1,3"]
|===
|Result|Value
|True|The folder holds no files. Subfolders do not count; with *Include subfolders*, the files in them do. With *Limit search to (RegExp)*, only files whose whole name matches *Wildcard (RegExp)* count.
|False|The folder holds a file: the number of errors is 0. The folder does not exist, the path is a file, or no folder name is set: the number of errors is 1.
|Result files|Passed on unchanged.
|Result rows|Passed on unchanged.
|Lines input|When the action is true, the number of subfolders found.
|===

NOTE: An invalid regular expression in *Wildcard (RegExp)* stops the workflow with an error, and no hop is followed, also when *Limit search to (RegExp)* is not selected.
