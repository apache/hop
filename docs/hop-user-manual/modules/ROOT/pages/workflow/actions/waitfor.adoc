= Wait For

== Description

The `Wait for` action creates a delay between workflow actions. The action allows to set a number of seconds, minutes or hours to wait before proceeding to the next action in the workflow.

== Options

[options="header", width="90%", cols="1,3"]
|===
|Option|Description
|Action name|The name of the workflow action.
|Maximum timeout|The time to wait, in the unit selected in the list below it: Seconds, Minutes or Hours.
|===

== Result

What this action passes on to the next action. See xref:workflow/action-results.adoc[Action results] for how results travel through a workflow.

[options="header", width="90%", cols="1,3"]
|===
|Result|Value
|True|The time is up. A *Maximum timeout* that is not a number counts as 0: the action doesn't wait. The number of errors of the previous action is kept: this action doesn't reset it. As the last action after an action with errors (for example a failed action on a failure hop), the workflow still ends as failed, although this action is true: add a xref:workflow/actions/success.adoc[Success] action after it to end the workflow successfully.
|False|Only when the workflow is stopped while the action waits, for example by an Abort in a parallel branch. No hop from the action is followed then.
|Result files|Passed on unchanged.
|Result rows|Passed on unchanged.
|===
