= FTP delete

== Description

The `FTP delete` action deletes files on an FTP server.

== Options

=== General tab

WARNING: The *SFTP* protocol of this action is deprecated.
It exists because the action was written before Hop could reach an SFTP server any other way.
It can now: the xref:workflow/actions/deletefiles.adoc[Delete files] action resolves its paths through VFS, so an xref:metadata-types/sftp-connection.adoc[SFTP Connection] or a plain `sftp://` path deletes remote files without a second implementation of the same thing.
Existing workflows keep working and log a warning; new ones should use Delete files.

2+|Server

Pick one and the server, credentials, transfer mode, timeouts and proxy settings below come from that connection; leave it empty to configure the server on this action. To connect with FTPS, use an FTP connection and its *Security* option.

== Result

What this action passes on to the next action. See xref:workflow/action-results.adoc[Action results] for how results travel through a workflow.

[options="header", width="90%", cols="1,3"]
|===
|Result|Value
|True a|Depends on *Success on*:

* All works fine (default): no file failed. No file matching the wildcard is also true, and so is *Copy previous results to args* without previous result rows.
* At least we delete x files: at least *Limit files* files were deleted.
* Nr errors less than: the number of errors is at most *Limit files*. An empty *Wildcard* counts as 1 error, so with this condition it gives true with 1 error.
|False|The success condition is not met, for example because the server can't be reached, the remote directory doesn't exist, or *Wildcard* is empty while *Copy previous results to args* is unchecked. The number of errors is the number of files that failed, or 1 when the action fails before deleting.
|Result files|Passed on unchanged.
|Result rows|Passed on unchanged.
|Files retrieved|The number of files deleted. When the remote directory has no files, or *Copy previous results to args* is checked without previous result rows, the value of the previous action is passed on unchanged.
|===

NOTE: With *Copy previous results to args*, the first field of each previous result row is the name of a file to delete in the remote directory, and *Wildcard* is not used.
