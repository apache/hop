= Canvas mouse gestures

The pipeline and workflow canvas react to where you click and with which button. This page is the reference for all of it. Three options in the xref:hop-gui/perspective-configuration.adoc[configuration perspective] (General tab, Canvas section) change the behaviour:

* **Use double click on canvas** — off by default. When on, a double-click opens the properties of the item under the pointer. A single click then does the same as without the option, but only after the double-click interval has passed, so that a second click can take over.
* **Use right click for the context dialog** — off by default. When on, a left click never opens the xref:hop-gui/hop-gui-popup-dialog.adoc[context dialog]; a right click does. Everything else a left click does (open properties from a name, press a badge, select, drag) stays the same.
* **Use menus instead of the context dialog** — off by default. When on, wherever this page says "context dialog" for a transform, action, hop or note, a pop-up menu with a submenu per category opens instead. The empty canvas keeps the context dialog while the xref:hop-gui/hop-gui-popup-dialog.adoc#palette-tree[palette tree] is hidden (that is where you search for transforms and actions to add); with the palette shown it gets a menu of the pipeline/workflow actions as well.

TIP: On macOS, `Ctrl`-click and a two-finger click both count as a right click. Where this page says `Ctrl`, use `Cmd` on macOS.

* **`X`** with the pointer over a transform or action icon opens the running execution, the same as `Alt`-click when that icon supports drill-down and a run is active. **`Z`** opens the referenced pipeline or workflow, the same as `Shift`+`Ctrl`-click. `X` and `Z` are Hop Gui shortcuts: Hop Web leaves a bare letter to the browser. `Alt`-click works in Hop Gui and Hop Web.
* **Left drag** on a transform, action or note moves it, together with everything selected. Dropping a transform on a hop offers to split the hop. Left drag on empty canvas draws a selection lasso.
* **Note edges** drag to resize the note.
* **`Esc`** cancels a hop in progress. A right click on empty canvas cancels it too.
* In **Hop Web** a drag starts as soon as you press the button; in Hop Gui the pointer has to move a few pixels first, so a small slip of the hand still counts as a click.
