= Configuration Perspective
// One level deeper than the default, so the contents list each plugin under
// Plugin options reference rather than stopping at the heading above them.
:page-toclevels: 3

Icon: image:icons/gear.svg[width="24px"]

Keyboard shortcut: `CTRL-Shift-C`

== Description

The configuration perspective offers a central location for all Apache Hop configuration options.

== Usage

The perspective lists its sections in a tree on the left. Selecting one shows its options on the right; the search box above the tree finds an option by name across all of them.

* **General**: how Apache Hop and Hop GUI behave - confirmations, tooltips and dialog positions.
* **Look &amp; Feel**: how Hop GUI is drawn on your desktop or in your browser.
* **Plugins**: one entry per plugin that contributes options, including xref:hop-gui/perspective-search.adoc[Search], the Explorer perspective and xref:hop-gui/perspective-ai-advisor.adoc[AI Assistant]. Every option is listed in <<_plugin_options_reference,Plugin options reference>> below.
* **System variables**: set and inspect the Apache Hop global variables.
* **Security**: how a session is authenticated, split over General, Basic, External and OAuth sub-tabs. Until authentication is turned on the session is unrestricted and anyone can change these settings, which the tab says at the top.
* **Keyboard shortcuts**: the shortcuts currently in effect, with the action each one triggers.

== Detailed options overview

=== General

The General tab holds the options that control how Hop GUI behaves rather than how it looks. The tables below follow the sections of the tab.

[%header, width=90%, cols="2,5,1"]
|===
|Option|Description|Default

|Hop configuration filename
a|Where Apache Hop stores `hop-config.json`, the file holding your projects, environments and global variables. Read-only here.

TIP: set the environment variable `HOP_CONFIG_FOLDER` to change this location, which makes switching between Hop versions and installations easy. xref:protips/index.adoc[read more]
|`<INSTALLATION_PATH>/config/hop-config.json`

|Preview data batch size
a|How many rows are fetched when previewing from the pipeline run toolbar or a transform preview dialog.

INFO: this complements the preview setting of the xref:pipeline/pipeline-run-configurations/native-local-pipeline-engine.adoc[native local pipeline run configuration], reachable through the image:transforms/icons/datagrid.svg[data grid, width="16px"] `preview data` icon in the bottom right corner of a transform after a run.
|1000

|Use database cache|Cache relational database metadata so repeated lookups of tables, fields and types do not go back to the server.|yes

|Reopen tabs on startup|Reopen the files that were open when Hop GUI last closed, and select the one that was active.|yes

|Enable embedded terminal
a|Show the embedded terminal in the bottom panel. Clear this on desktops where that terminal misbehaves; search, the database workbench and the VFS file explorer stay available either way. Hop Web has no embedded terminal. Excluding `40010-menu-tools-terminal` in xref:hop-gui/disable-ui-elements.adoc[disabledGuiElements.xml] forces it off.
|yes

|Reload file if changed on filesystem|Reload a pipeline or workflow when it changes outside Hop GUI, for example after a `git pull` or an edit in another editor.|no

|Sort field names alphabetically in dropdowns|Sort field names in dropdown lists alphabetically. When off, fields keep the order they arrive in from the incoming stream.|yes

|Use global bookmarks in the file dialog|Share the file dialog's bookmarks across every project instead of keeping a separate set per project.|yes

|Maximum execution logging text size|The largest amount of log text held for the execution information perspective, in characters. Caps memory use on long-running or very chatty executions.|2000000
|===

==== Confirmation dialogs

Each option here controls one confirmation pop-up. Turning one off does not change what the action does, only whether Hop asks first. Every one of these dialogs can also be switched off from the dialog itself, with its *Do not ask this again* option.

[%header, width=90%, cols="2,5,1"]
|===
|Option|Description|Default

|Show confirmation when exiting Hop|Ask for confirmation before closing Hop GUI.|yes

|Show copy or distribute dialog when drawing a hop|Ask whether rows should be copied to, or distributed round-robin over, the following transforms when a second hop is drawn out of a transform.|yes

|Show confirmation when splitting hops|Ask before splitting a hop when a transform or action is dropped onto it. With this off, the hop is split without asking. Hops that a dropped item would split are drawn in bold.|yes

|Show confirmation to save file when starting pipeline or workflow|Ask whether to save a changed file before running it. With this off, the file is saved automatically on every run.|yes

|Reset all to enabled (Includes Action/Transform warnings)|Button. Switches every confirmation dialog back on, including the per-transform and per-action warnings that were dismissed with *Do not ask this again*.|on click
|===

==== Tooltips

[%header, width=90%, cols="2,5,1"]
|===
|Option|Description|Default

|Show tooltip when hovering over a hop or Action/Transform|The master switch for the canvas tooltips. With this off, none of them appear, whatever is ticked under *Tooltips* in the xref:hop-gui/perspective-configuration.adoc#_look_feel[Look & Feel] tab.|yes

|Show resolved variables in tooltips|Show what a variable currently resolves to in the tooltip, rather than the `+'${VARIABLE}'+` expression as written.|yes

|Reset all to enabled|Button. Switches every tooltip option back on.|on click
|===

==== Dialog positioning

[%header, width=90%, cols="2,5,1"]
|===
|Option|Description|Default

|Remember dialog positions|Reopen each dialog at the position and size it was last given. With this off, every dialog opens at its default position and size.|yes

|Reset dialog positions after restart|Keep remembered positions for the current session only, clearing `shells-state.json` on restart. With this off, positions are also written to that file and restored the next time Hop GUI starts. Only has an effect while *Remember dialog positions* is on.|no

|Clear dialog positions|Button. Forgets every remembered dialog position and resets the perspective tree-panel widths to their defaults. Useful after moving between monitors of different sizes, when a dialog reopens off-screen.|on click
|===

=== Look & Feel

The Look & Feel tab holds everything about how Hop GUI is drawn: fonts, colours, the canvas, and which columns and toolbars are shown. The tables below follow the sections of the tab.

Some of these settings only take effect after Hop GUI is restarted; the dialog says so where that is the case.

==== General appearance

[%header, width=90%, cols="2,5,1"]
|===
|Option|Description|Default

|Preferred language
a|The language Hop GUI is shown in.

TIP: Check the https://hop.apache.org/community/contribution-guides/translation-contribution-guide/[Translation Contribution Guide] to translate Apache Hop into your own language.
|English (US)

|Hide the menu bar|Hide the menu bar. With it hidden, the menu is reachable from the Apache Hop icon in the upper left corner of Hop GUI.|yes

|Dark mode|Use the dark theme. On Hop Web and Windows this is a straight toggle; on macOS and other desktop platforms the theme follows the operating system. Changing it in Hop Web reloads the page.|follows the OS

|Follow system dark mode (Hop Web)|Take the light or dark setting from the system or browser. While this is on, the *Dark mode* option above is disabled.|no

|UI zoom level|The zoom level pipelines and workflows open at.|100%

|Icon size in workspace|The size transform and action icons are drawn at on the canvas, in pixels.|32

|Line width on workspace|The width hops are drawn with on the canvas, in pixels.|1

|Dialog middle percentage|Where the divider between labels and input fields sits in dialogs, as a percentage of the dialog width. Raise it where a translation makes labels too wide for their column.|35
|===

==== Pipeline and Workflow canvas

[%header, width=90%, cols="2,5,1"]
|===
|Option|Description|Default

|Show canvas grid|Draw the dotted alignment grid behind pipelines and workflows.|no

|Canvas grid size|The spacing of that grid, in pixels. Transforms and actions snap to it.|16

|Show viewport|Show the viewport, the small overview of the whole pipeline or workflow in the bottom right corner of the canvas.|yes

|Use double click on canvas
a|Enabled: double-click a transform or action icon to open its properties; a single click opens the context dialog.

Disabled (the default): a single click on the icon opens the context dialog, and a click on the name opens the properties.

See xref:hop-gui/canvas-mouse.adoc[Canvas mouse gestures] for every click in both modes.
|no

|Use right click for the context dialog
a|A right click (Ctrl-click or a two-finger click on macOS) opens the context dialog of whatever is under the pointer, and a left click never does: it selects, clears the selection, or presses a badge. Names and badges still open their editors on a left click.

See xref:hop-gui/canvas-mouse.adoc[Canvas mouse gestures] for every click in both modes.
|no

|Use menus instead of the context dialog
a|Transforms, actions, hops and notes show their actions in a pop-up menu with a submenu per category rather than in the xref:hop-gui/hop-gui-popup-dialog.adoc[context dialog]. A click on the empty canvas keeps the context dialog while the xref:hop-gui/hop-gui-popup-dialog.adoc#palette-tree[palette tree] is hidden, since that is where new transforms and actions are searched for; with the palette shown, the empty canvas gets a menu of the pipeline and workflow actions instead. The click that opens the menu is the same one that opens the context dialog.
|no

|Draw border around Action/Transform names on canvas|Draw a border around the names of transforms and actions, which helps where names overlap the icons behind them.|no

|Enable infinite move|Pan the canvas in every direction without being stopped at the origin, so a diagram can be built out to the left of or above where it started.|no

|Disable zoom scrolling|Stop the mouse scroll wheel zooming the canvas in and out. Useful on trackpads where scrolling and zooming are easy to confuse.|no

|Metrics above selected running transforms?|While a pipeline runs, draw its metrics above the transforms that are selected.|yes

|Tooltips
a|One checkbox per kind of tooltip the canvas shows when the mouse rests on something. Untick one to stop only that kind. *Show tooltip when hovering over a hop or Action/Transform*, in the *Tooltips* section of the General tab, switches all of them off at once.

* *Edit hint on transform and action names*: the "Click to edit" hint on a name.
* *Transform and action descriptions*: the description on an icon and its info badge, along with the transform partitioning and whether a transform can start a pipeline.
* *Deprecation warnings*: the warning on the icon of a deprecated transform or action, and its replacement.
* *Hop details*: the source, target and status of a hop, and the badges on it: info, error, copies, row distribution, target streams and the conditions of workflow hops.
* *Execution results*: after a run, the failure logs, the rows a transform or hop holds, the result of an action and where a workflow restarted from a checkpoint.
* *Note links*: where a hyperlink in a note leads.
* *Plugin tooltips*: tooltips that plugins add to the canvas, such as the custom debug levels.
* *Selection cleared notice*: the short "Selection cleared" notice after a click on the empty canvas while something was selected.
|all on

==== Auto-layout

These settings control the *Arrange* action, which lays a pipeline or workflow out automatically.

[%header, width=90%, cols="2,5,1"]
|===
|Option|Description|Default

|Layout direction|The direction the graph flows from start to end: left to right, right to left, top to bottom or bottom to top.|Left to right

|Layer spacing|The distance between consecutive layers, along the flow direction, in pixels.|150

|Node spacing|The distance between nodes within one layer, across the flow direction, in pixels.|120

|Crossing-reduction iterations|How many barycenter sweeps are used to pull crossing hops apart. Higher is tidier but slower on large diagrams.|4

|Move notes with nearest node|Move each note along with the transform or action it sits closest to. Notes that are not near any of them stay where they are.|yes
|===

==== Tables and grids

[%header, width=90%, cols="2,5,1"]
|===
|Option|Description|Default

|Show toolbar|Show a toolbar above table grids with cut/copy/paste, move row up/down, go to column and xref:pipeline/run-preview-debug-pipeline.adoc#table-views[table views]. Applies to preview dialogs, transform settings and similar grids.|yes

|Show text editor toolbar|Show a toolbar above multi-line text editors (SQL, scripts and similar fields) with cut/copy/paste, undo/redo and find/replace.|yes

|Maximum data grid cell length
a|The most characters drawn in one cell of a data grid: the row preview, the data grid transform and the rows viewers. Longer values are only shortened on screen; click a cell to see the whole value in place, or use the expand icon to open it in the multi-line editor. Copying, exporting and saving always use the full value. Set it to 0 to stop shortening.

|50

|Show line breaks as symbols in data grid cells
a|Draw line breaks and tabs inside a data grid cell as symbols on a single line. With this off, a value containing a line break is cut at the first break and marked with an ellipsis. |no

=== Plugins

The plugins tab contains configuration options that are provided by the various plugins in Apache Hop.

The following plugins are available by default:

* xref:vfs/azure-blob-storage-vfs.adoc#_configuration[Azure Blob Storage] VFS configuration options.
* xref:vfs/dropbox-vfs.adoc#_configuration[Dropbox] VFS configuration options.
* **Explorer perspective**: Configuration options for the file explorer perspective:
  ** The initial depth to load not lazily: Controls how many folder levels are loaded immediately when opening folders.
  ** The maximum file size to load: Sets the maximum file size (in MB) that will be loaded when opening files.
  ** Show file explorer panel by default: When enabled, the file explorer panel (project tree) is shown by default when opening the explorer perspective. When disabled, the panel starts hidden.
  ** Open help pages in: Where Hop GUI opens documentation from Help buttons and F1. *External browser* (default) uses the system browser. *Hop GUI tab* opens an HTML tab in the File Explorer perspective. *Dialog window* opens a modeless help window on top of the current dialog or main window so you can keep editing.
+
image::hop-gui/configuration-perspective-open-help-pages-in.png[Open help pages in,width="90%"]
* xref:technology/google/index.adoc[Google Cloud] configuration options (service account JSON key file).
* xref:vfs/google-drive-vfs.adoc#_configuration[Google Drive] VFS configuration options.
* xref:projects/index.adoc[Project] configuration options
* Welcome Dialog: specify whether to show or hide the welcome dialog when Hop GUI starts.
* **File validation**: when enabled (the default), saving a pipeline or workflow warns if a transform or action references a relational database connection that is not in the project metadata. You can still save. Connection names that still contain a variable such as `+'${CONNECTION}'+` after the current environment is applied are skipped, because the name cannot be decided at design time. The same check also runs when you Verify a pipeline or workflow. Hop does not try to open a JDBC connection as part of this check.
+
image::hop-gui/configuration-perspective-file-validation-validate-database-connections-when-saving.png[Validate database connections when saving,width="90%"]
+
The warning lists the missing connections. *Yes* saves anyway, *No* cancels the save. Check *Don't run this check when saving* to turn the option off; you can turn it back on here.
+
image::hop-gui/validate-database-connections-on-save-warning-dialog.png[Database connections save warning,width="90%"]
