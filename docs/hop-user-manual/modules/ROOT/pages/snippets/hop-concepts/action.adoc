An Action is a single operation performed in a Workflow.
Actions are executed sequentially one after another by default, with parallel branch execution available as a configuration option.
When an action finishes, it returns a success or failure status (true or false).
This status determines which outgoing hops the workflow follows next.
Actions can also pass variables, lists of files, and summary rows to subsequent actions.
See the xref:workflow/actions.adoc[Actions catalog] for all available workflow actions.
